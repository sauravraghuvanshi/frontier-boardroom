- Cloud marketplace (Azure/AWS): 3% marketplace fee + 5–10% co-sell incentive for sales rep.

## Risk register
- **Partner conflict**: Microsoft Foundry partnership in conflict with Microsoft's own GitHub Copilot business unit. Mitigation: our agent product is positioned as "code review + on-call + infra ops" (not IDE completion), reducing direct overlap.
- **Marketplace dependency**: if Azure Marketplace listing delayed past Q3, SEA enterprise close rate drops ~12% (modeled from comparable transactions).
