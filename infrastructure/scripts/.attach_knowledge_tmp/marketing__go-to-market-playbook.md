# Contoso AI — SEA GTM playbook (2026)

## Strategic posture
SEA = "follow-the-engineering-org" not "follow-the-flag". We chase eng orgs of 50–2000 devs that we can convert in a 6–10 week sales cycle with the Code Review Agent as the spear.

## 5-step playbook
1. **Anchor on Singapore** — HQ, English-default, regulatory clarity, highest brand awareness in SEA.
2. **Land via 3 founder-led design partners by end of Q1 2026**. Target profile: 100–400 devs, regulated industry (fintech preferred), willing to deploy Code Review Agent on a real repo within 2 weeks.
3. **Hire local SDR + AE in Singapore + Jakarta by end of Q2 2026.** SG team supports SG+MY+TH; Jakarta team supports ID+VN.
4. **PR moment at Tech in Asia (June 2026)** with 3 named SEA design partners and Country GM SG announcement.
5. **Channel partner deal** with a regional SI (e.g. NCS or MII) for ID + VN to amplify reach without growing direct sales headcount.

## Sales motion
- **Top of funnel**: dev-led inbound (blog, podcast sponsorships, GitHub trending tools), supported by LinkedIn ABM on ~600 named SEA accounts.
- **Mid-funnel**: 14-day PoC on customer code, with eng lead + Contoso SE jointly running the eval.
- **Close**: enterprise tier ($249/seat/mo), 12-month commit, 1 paid pilot quarter that converts.

## Pricing posture for SEA
- SG: list price (premium positioning).
- ID/VN/TH: 15% off list for committed-multi-year deals — preserves anchor pricing in SG.
- Free-tier: 5 dev seats free forever, allows bottom-up adoption inside engineering teams.

## Failure modes to avoid
- **Don't try to localize the admin UI** — 14/14 SEA interviews prefer English. Spending eng cycles on Bahasa Indonesia admin UI is wasted effort.
- **Don't compete on price with BetaCode** — they're 50%+ cheaper and we lose on margin. Compete on agent quality and SLA.
- **Don't open VN LLC in 2026** — use SG entity + EOR, defer LLC to 2027 once $1M ARR in VN.
