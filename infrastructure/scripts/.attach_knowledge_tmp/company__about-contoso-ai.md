# About Contoso AI — A Frontier Firm

**Mission**: Build world-class AI agents that automate the daily work of engineers.

**Tagline**: *Built in India, for the world.*

## What we do
Contoso AI builds production AI agents that work inside software engineering teams. Our agents review pull requests, triage incoming PRs, generate tests, respond to on-call alerts, and review infrastructure-as-code changes — all while respecting per-tenant data residency, audit, and security requirements.

We do not build:
- IDEs (we plug into existing IDEs).
- Code completion (we compete on review + ops, not inline completion).
- Customer-support chatbots (different market segment).

## Why "Frontier"
The Frontier moniker describes how we run the company: a small set of strongly-opinionated decisions made every week by an AI-augmented "boardroom" of five executive agents. This is also the inspiration for the demo product **Contoso AI Boardroom**, a Microsoft Agent Framework reference application that the company uses to debate strategic decisions in front of customers and investors.
